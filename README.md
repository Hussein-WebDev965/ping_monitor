# Ping Monitor

سكربت بايثون يراقب أجهزة الشبكة ويرسل تنبيه على تيليغرام عند وقوع جهاز أو رجوعه.

## المميزات
- فحص عدة أجهزة بشكل دوري
- تنبيه فقط عند تغيّر الحالة (بدون تكرار)
- يشتغل على ويندوز ولينكس

## التشغيل
1. pip install requests
2. انسخ config.example.py باسم config.py وضع التوكن والـ Chat ID
3. عدّل قائمة DEVICES بعناوين أجهزتك
4. python ping_monitor.py
